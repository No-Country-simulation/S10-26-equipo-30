# Prototipo web (Vercel)

App funcional o click-through del flujo UXFlow. **Root Directory en Vercel:** `prototipo`.

## Local (cuando exista el proyecto)

```bash
cd prototipo
npm install
npm run dev
```

## Deploy

1. Conectar el repo en Vercel.  
2. Settings → General → **Root Directory** → `prototipo`.  
3. Production desde `main`; previews por PR.
